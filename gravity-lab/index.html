How it works

Gravity is computed with a Barnes–Hut quadtree: distant cells are collapsed to their centre of mass when size/distance < θ, turning an O(n²) sum into O(n log n). Integration is leapfrog KDK — symplectic, so orbits stay closed instead of spiralling away the way Euler would. Accelerations are cached across substeps, so each step costs exactly one tree build.

Everything is drawn on a 2D canvas with lighter compositing and a pre-baked glow sprite LUT. No WebGL, no Three.js, no build step. Same seed, same preset, same universe — the PRNG is deterministic.
