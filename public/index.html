    Each star is a real commit pulled live from the GitHub REST API. Colour = author, size = commit "weight", position = place in history. During playback every star triggers a note in a pentatonic scale, so the repo's rhythm becomes a melody.

    Built with zero dependencies: Node's http module on the server, Canvas 2D + Web Audio in the browser.
